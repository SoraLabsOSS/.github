# Sora Labs

Sora Labs builds open-source **UI component libraries and developer tools** for modern web apps — including [Sora UI](https://ui.soralabs.io.vn), a motion-first component registry for React and Next.js, and [Sora Type](https://type.soralabs.io.vn), a client-side font inspector and preview app for developers and designers.

We host most of our open-source projects here on GitHub and every contribution is welcome!
